# Documentación de testing SIHS

Esta carpeta reúne las guías de pruebas e informes históricos del proyecto. La metodología y evidencias recientes del bootcamp están disponibles en las ramas semanales.

- [Informes históricos de pruebas](./informes-historicos/README.md).
- Los tests de backend deben permanecer en `backend/tests/`.
- Los tests de frontend deben centralizarse en `frontend/tests/` cuando se integre su migración aprobada.
- Las pruebas de navegador están en `e2e/tests/`.

La estructura de la rama `main` se mantiene separada de los entregables aún en desarrollo; no incorporar archivos funcionales incompletos para forzar una coincidencia con `develop`.
